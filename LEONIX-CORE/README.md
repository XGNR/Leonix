# LEONIX CORE

The central workspace for LEONIX's original, independently developed code.

## Purpose

This directory will contain the project's core components as they are implemented and tested. Work here is focused on reusable foundations for an open-world-style technology research project, such as:

- configuration and application startup
- performance measurement and diagnostics
- graphics and rendering experiments
- logging and error reporting

## Development rules

- Use original code and assets, or materials that we are authorized to use.
- Keep experimental features clearly marked until tested.
- Record reproducible test results; do not claim unverified compatibility or performance.
- Keep dependencies minimal and document them before adding them.

## Current status

**Scaffolding only.** No runtime features are implemented in this directory yet.

## Next step

Choose the first core component to implement, then add its source code and tests together.
