# LEONIX Roadmap

This roadmap describes planned research areas. Items are goals, not promises of completed features.

## Research foundation
- [ ] Organize project documentation
- [ ] Define a repeatable test-report format
- [ ] Document the development environment

## Performance research
- [ ] Establish baseline benchmark procedures
- [ ] Record frame-time and frame-rate measurements
- [ ] Investigate memory and CPU usage

## Graphics research
- [ ] Document rendering observations
- [ ] Investigate lighting and shadow consistency
- [ ] Record visual test results using authorized assets

## Release preparation
- [ ] Add original project screenshots
- [ ] Publish verified system requirements
- [ ] Prepare installation instructions after a testable release exists
