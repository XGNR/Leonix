## [0.1.0] — Initial Development

### Development Progress
- Investigated Xbox file compatibility.
- Researched Xbox-to-PC file format compatibility.
- Created an executable (`.exe`) prototype.
- Established connections between the executable and test files.
- Successfully launched the executable.
- Displayed the initial loading screen.
- Accessed the initial game settings screen.
- Configured the initial scripts.
- Recorded an initial performance output of 3 FPS.
