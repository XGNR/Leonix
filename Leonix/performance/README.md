# Performance & FPS Research

This section records frame-rate behavior and the conditions under which it was observed.

## Metrics

- **Average FPS:** average frames rendered per second during the defined capture.
- **1% low FPS:** a measure of slower frame delivery; document the tool and calculation method.
- **Frame time:** time between presented frames, recorded in milliseconds.
- **Stutter:** a noticeable interruption or irregularity in frame delivery.
- **Capture duration:** the exact length of each measurement.
