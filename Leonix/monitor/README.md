# System Monitoring Records

Use this section to document the hardware and system conditions accompanying each GTA VI test.

## Telemetry checklist

| Component | Values to record |
| --- | --- |
| CPU | Exact model, utilization, clock, temperature, power if available |
| GPU | Exact model, utilization, clock, temperature, power if available |
| System memory | Installed RAM, used RAM, available RAM |
| Video memory | Dedicated VRAM usage and total capacity, if reported |
| Storage | Drive type, free space, activity, and loading observations |
| Operating system | Edition, version, and build |
| Driver | GPU driver version |
| Background load | Relevant applications or unusual activity |

## Monitoring record

- Record ID: Not assigned
- Date and time: Not recorded
- Monitoring tool and version: Not recorded
- Sampling interval: Not recorded
- Game build and platform: Not verified
- Sensor values: Not measured
- Evidence: Not provided

## Important

Sensor readings vary by hardware, driver, monitoring software, sampling interval, and workload. Always identify the measurement tool. Do not infer CPU or RAM usage from an FPS number alone.
