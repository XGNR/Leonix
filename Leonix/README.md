# LEONIX — GTA VI Technical Research

**An independent research and documentation project by XGNR.**

> A Man from Iran, A Lion from Khuzestan.

LEONIX is a structured research hub for documenting observable Grand Theft Auto VI performance, system behavior, graphics settings, test results, and technical issues.

**This repository section is documentation and research records — not a game, launcher, mod, patch, or executable optimization tool.**

## Research areas

| Area | What is documented |
| --- | --- |
| System monitoring | CPU, GPU, memory, temperatures, storage, and operating-system context |
| Frame performance | Average FPS, 1% lows, frame times, stutter observations, and test conditions |
| Graphics | Resolution, quality settings, ray tracing options, upscaling, and visual observations |
| Benchmarks | Repeatable test procedures, test cases, and measured results |
| Stability | Crashes, freezes, visual defects, and reproducible problems |
| Configuration | Hardware profiles, software versions, and test environment details |

## Repository map

- `src/` — research source notes, evidence references, and data definitions
- `core/` — project scope, methodology, and issue tracking
- `performance/` — FPS and frame-time records
- `monitor/` — CPU, GPU, RAM, and system telemetry records
- `benchmarks/` — test plans, test cases, and result logs
- `config/` — reusable test-environment profiles

## Evidence and accuracy policy

- No benchmark result is published without a traceable source or a recorded test.
- Unknown values are marked **Not measured**; estimates are never presented as measurements.
- Every performance result must include its platform, hardware, game build, settings, and test scenario when known.
- Third-party reports must be attributed and distinguished from XGNR's own testing.
- Only lawfully obtained game copies and authorized materials may be used for testing. Do not upload game files, extracted proprietary assets, or copyrighted content.
