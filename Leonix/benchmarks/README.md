# Benchmark Lab

This section contains repeatable test plans and the official LEONIX result register.

## Test case checklist

| Test ID | Test focus | Required observation |
| --- | --- | --- |
| PERF-001 | Frame-rate capture | Average FPS, 1% lows, frame times |
| SYS-001 | CPU telemetry | Utilization, clock, temperature |
| SYS-002 | Memory telemetry | RAM and VRAM usage |
| GFX-001 | Graphics comparison | Same scene, documented settings |
| LOAD-001 | Loading behavior | Timed load and transition observations |
| STAB-001 | Stability session | Duration, crash or freeze occurrence |
| ISSUE-001 | Problem reproduction | Steps, frequency, evidence |

These are planned test cases, not completed tests.

## Minimum conditions for a valid result

1. State the exact test objective.
2. Record hardware, operating system, drivers, and game build when available.
3. Record graphics settings and the test scene.
4. Use a consistent capture duration and measurement tool.
5. Save the raw result or a lawful evidence reference.
6. Repeat the test where practical and report variation.
7. Mark incomplete or conflicting results clearly.

Never invent results to fill an empty table.
