# Research Test Cases

The following cases define what LEONIX intends to measure. They are not claims that tests have already been run.

## PERF-001 — Frame Delivery
**Objective:** Record average FPS, 1% low FPS, and frame-time behavior in a defined scene.

**Record:** Platform, game build, hardware, settings, capture tool, duration, and evidence.

## SYS-001 — CPU Behavior
**Objective:** Observe CPU utilization, clock behavior, and temperature during a documented workload.

**Record:** CPU model, monitoring tool, sampling interval, and background activity.

## SYS-002 — Memory Behavior
**Objective:** Record system RAM and GPU VRAM usage during a defined scene or session.

**Record:** Installed capacity, used amount, monitoring tool, and capture time.

## GFX-001 — Graphics Settings Comparison
**Objective:** Compare visual and performance observations between documented settings.

**Rule:** Change one relevant setting at a time where practical; keep scene and capture conditions consistent.

## LOAD-001 — Loading and Streaming
**Objective:** Document loading durations and visible streaming interruptions.

**Record:** Start/end definition, storage device, route or scene, repetitions, and observations.

## STAB-001 — Stability
**Objective:** Record crashes, freezes, or abnormal exits during a defined session.

**Record:** Session duration, platform, build, reproduction steps, and authorized log references.

## Completion status

All cases are currently **Planned**. Mark a case complete only after the method and evidence have been reviewed.
