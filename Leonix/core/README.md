# Core Research Methodology

This section defines how LEONIX records observations and handles technical problems.

## Research domains

1. CPU workload and utilization
2. GPU utilization and graphics behavior
3. RAM and video-memory usage
4. Average FPS, 1% low FPS, and frame-time consistency
5. Loading, streaming, and storage behavior
6. Graphics quality and image reconstruction
7. Temperature, power behavior, and system stability
8. Crashes, freezes, visual defects, and reproducible errors

## Issue report template

| Field | Record |
| --- | --- |
| Issue ID | Not assigned |
| Title | Describe one specific problem |
| Game build | Not verified |
| Platform | Not recorded |
| Hardware | Not recorded |
| Reproduction steps | Add clear, repeatable steps |
| Expected behavior | What should happen |
| Observed behavior | What actually happened |
| Frequency | Every time / Sometimes / Once |
| Evidence | Public source or authorized screenshot reference |
| Status | Unverified |

## Quality standard

A problem is not confirmed until another person can understand the conditions and reproduce it, or a reliable source independently documents it. Keep suspected causes separate from confirmed observations.
