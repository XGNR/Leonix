# Research Source Index

This folder is reserved for source notes, measurement definitions, and references that support LEONIX research.

It is **not** an executable application source tree.

## Source record format

For every external source or test artifact, record:

- Title and publisher / author
- Public URL or internal evidence reference
- Publication or capture date
- Date accessed
- What claim or measurement it supports
- Limitations, missing context, and confidence

## Data rules

- Preserve original units and wording when transcribing measurements.
- Never convert an estimate into a confirmed result.
- Do not store passwords, account details, personal information, game binaries, or proprietary game assets here.
- Link to lawful public sources instead of copying copyrighted material.

No source-backed GTA VI performance dataset has been added yet.
